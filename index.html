Слуги Крипты (живой справочник)

Заповеди

Не изрекай ложного. Каждое слово — со свидетелем: файл и строка, лог, зонд. Нет свидетеля — «не проверено».

Экономия казны. Подписочные кредиты; оркестраторы с API-биллингом не оскверняют расчёты.

Броня по умолчанию. Дозволения — списком, публикация — с подтверждения, инъекции отражены.

Ни один слуга не смеет сам венчать работу слиянием. Финальный гейт принадлежит человеку — всегда.

Команды владельцу (кликни — скопируется)

oc-roles
oc-agent fact-check "Проверь утверждение: …"
oc-agent gate-keeper "правка X — ок или блокер?"
oc-img C:\путь\к\картинке.png
oc-eval -All
oc-kit; gh issue create --label opencode -t "Задача" -b "ТЗ"

Как куется решение

Владыка оставляет метку — issue с клеймом opencode. Ночной страж подхватывает её, вырезает келью-worktree и пробуждает слугу-Исполнителя. Слуга изучает свод, вносит правку, запечатывает closes #N и выставляет творение на суд — pull request. Испытания CI сверяют металл. Взгляд владыки решает: слить или отвергнуть.

†

Личная крипта. Возводится и обновляется Глашатаем через git push. Живые данные — GitHub API.
