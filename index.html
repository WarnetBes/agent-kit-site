AI Engineering Factory

Домашняя автономная фабрика разработки: задача → агенты → PR → проверка → релиз. Мерж — всегда человек.

22 роли

Исполнитель, Тестировщик, Ревизор, Охранник, Факел, Фактчек, Механик, Санитар, Гейм-мастер, Глашатай и другие — с русскими именами.

Автономный цикл

GitHub Issue → worktree → headless-агент → PR → CI → мерж владельцем. Ноль ручных шагов, кроме финального решения.

Гейты честности

Факел против reward-hacking, Фактчек по первоисточникам, eval-harness 10 golden-задач против регрессий.

Зрение и мосты

OCR-зрение для изображений, веб-глаза (search/fetch), мосты Roblox/Blender, Telegram-уведомления.

Как это работает

Владелец ставит задачу issue с лейблом opencode. Watcher подхватывает её, создаёт отдельный worktree и запускает агента-Исполнителя headless. Агент изучает репозиторий, вносит правку, коммитит с closes #N, открывает PR. CI гоняет тесты. Человек смотрит PR и мержит — это осознанный гейт, автомержа нет.

Принципы

Без галлюцинаций. Каждое утверждение — с источником: файл:строка, лог, зонд. Нет данных — «не проверено», а не догадка.

Harness-native. Подписочные кредиты моделей, никакого API-биллинга за токены.

Безопасность по умолчанию. Точечный allow-list команд, publish-гейты, защита от инъекций из issue-текста, мерж только человеком.

Статус

Развёрнута и верифицирована живыми PR; eval-прогон ролей — 10/10. Полная инструкция — в репозитории фабрики (FACTORY.md).
